# 데이터 공급원 검증

상태: **일부 공개 과거 프레임 조회 및 오프라인 검증 완료**. 공개 저장소의 키를 복사하거나 하드코딩하지 않았다. 상용/재배포 권한과 자동 라이브 수집은 별도 미검증이다.

2026-10-16 추가: 개인용 공개 공급자를 구현해 API 키 없이 공개 일정 HTML과 통계 feed에 연결했다. 실제 일정 조회와 로컬 서버의 live 모드 응답은 확인했으나, 진행 중 Worlds가 없어 연속 라이브 수신 검증은 대기 중이다. [검증 기록](unofficial_live_validation.md).

후보는 명세에 지정된 비공식 LoL Esports API. persisted 경기/일정/상세와 feed window/details는 서버 adapter로 분리했다. 2026-09-13 LCK 결승 GEN–HLE 1세트의 약70초 원본과 종료 스냅샷을 키 없이 조회했다. 실제 프레임 형식과 통계 정규화는 검증했으며, 권리·호출 제한·실시간 지연은 아직 검증하지 않았다.

라이브 활성화 전 기록할 증거:

- [ ] 접근/재배포 권한과 서비스 조건
- [ ] 서버 전용 인증 정보, 비밀정보 제거된 응답 fixture
- [ ] Worlds의 match/game/team ID 및 진영 전환
- [ ] 게임 시간·킬·골드·타워·드래곤·바론·영혼·장로·공식 승자 지원 여부
- [ ] source timestamp와 수신 시각, 공식 중계 대비 지연 측정표
- [ ] 429/401/403 및 공급 중단 대응

확정되지 않은 시간·오브젝트 종류·승자는 생성하지 않는다. 공급원 window에 게임 시간이 없으면 타이머는 --:--, 종료 상태만 있고 승자가 없으면 승리 사건은 생성하지 않는다. 현재 adapter는 공식 승자 응답 검증 전이므로 실전 GAME_END를 보장하지 않는다.

실제 검증 기록: [2026 LCK 캡처 테스트](lck_2026_capture_test.md). 공개 일정 HTML에서 세트 ID를 확보했으며 getLeagues의 인증 없는 호출은 403이었다. getLive/getSchedule을 통한 자동 경기 발견은 이번 테스트에 포함하지 않는다.
